# Alkane isomer counts (OEIS A000602): asymptotic constants and closed-form non-existence certificates

Computational study of the sequence **A000602** — the number of structural
isomers of the alkane CₙH₂ₙ₊₂, equivalently the number of unlabeled, unrooted
trees on *n* vertices with maximum degree 4.

**⚠ Provenance: the mathematics, code, and manuscript in this repository were
generated by an AI assistant.** See [PROVENANCE.md](PROVENANCE.md) before
citing. Every claim is machine-checkable by running the scripts below; nothing
asks to be taken on trust.

## Results

**1. Asymptotic expansion with certified constants** (apparently unpublished
beyond the leading term):

    a(n) ~ C · α^n · n^(−5/2) · (1 + c₁/n + c₂/n² + ...)

    α  = 2.81546003317615074652661677824269954253651...   (growth constant; = 1/ρ)
    ρ  = 0.355181742314377392882244473647632636708747...   (= OEIS A261340)
    C  = 0.65631869584183475...
    c₁ = 0.0300686950399...
    c₂ = 4.7882749807...
    c₃ ≈ 22.18

The growth constant and ρ are published (Kotesovec 2015 on A000598; A261340);
the unrooted amplitude C extends Finch's ~10 digits (§5.6.1); c₁–c₃ and the
bounds below appear to be new.

Certified empirical error bounds on 25 ≤ n ≤ 600: the 1-, 2-, 3-term
truncations have relative error ≤ 0.276/n, 6.16/n², 35.5/n³ respectively.

**2. Non-existence certificates for exact closed forms.** Exhaustive,
exact-arithmetic (modular) searches prove that a(n) satisfies:

- **no polynomial-coefficient recurrence** (homogeneous or inhomogeneous) in a
  staircase region up to order 2/degree 150, order 10/degree 46, order 304 with
  constant coefficients — eliminating all Wilf–Zeilberger-class
  (binomial/Γ/hypergeometric finite-sum) closed forms with canonical
  annihilator in that region;
- **no algebraic equation** P(x, A(x)) = 0 with deg_y ≤ 28 (staircase), and no
  first-order algebraic ODE of degree ≤ 7 per variable;
- **no small digit-automatic structure**: the 2-kernel of a(n) mod 2 grows
  maximally (≥ 31 states through depth 4), no eventual periodicity mod 2..7
  with period ≤ 200.

**3. Localization of the obstruction.** The *labeled* analogue has an exact
two-index finite-sum closed form (derived and verified herein) — so the
valence-4 constraint is harmless; the unlabeled quotient (Burnside sum over
all partitions of n) is the entire 150-year-old difficulty, and the one known
collapse mechanism (Rademacher's modular circle method) is structurally
unavailable for this mixed (2,3)-Mahler system.

Full statements, proofs, tables, and references: `noA_certificates.pdf`.

## Reproducing

Requires Python ≥ 3.9 with `numpy` and `mpmath`:

```sh
python asym.py          # constants + error table        (~1 min)
python bounds.py        # certified bounds scan          (~1 min)
python solveA.py        # all non-existence certificates (~2 min)
python verify_bfile.py  # data certification vs OEIS
python crosscheck.py    # pipeline validation vs published constant
```

Each certificate in the paper corresponds to a "full rank" line in
`solveA.py` output; the searches are validated by planted decoys (Catalan,
Thue–Morse) that the same code *does* find.

## Status of the results

- The leading asymptotic form is classical (Pólya 1937; constants:
  Robinson–Harary–Balaban 1976, Finch 2003). New here: the correction
  coefficients c₁–c₃, the certified error bounds, and (to our knowledge) all
  of the non-existence certificates.
- The certificates are rigorous modulo correctness of exact integer/modular
  arithmetic; full rank modulo a single prime is a proof of non-existence
  over ℂ (see paper, §3).
- The natural-boundary and global non-holonomicity statements are
  conditional/structural and clearly flagged as such in the paper (§7).
